# Saved behavior profiles

Save profile and Load profile open this folder by default. Save your experiment
or rig configurations here as `.json` files. Parameter edits, including daily
`UnitRewardSize` calibration, are stored inside each profile.

You can still browse to profiles saved elsewhere. Profiles are saved and loaded
only when you request it; no example profile or automatic startup profile is
created. See [the GUI guide](../README.md#profiles-and-logs) for details.
